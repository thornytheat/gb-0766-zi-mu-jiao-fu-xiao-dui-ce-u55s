# C101 帧边界复算

C101 原行 2，覆盖从 900 到 1300 源帧。A-01 保留 100 源帧，A-02 移除 200 源帧，B-01 保留 100 源帧。B-01 从源 1200 锚到目标 810，末端是 `810+100×1001/1250=890.08`，因此交付 `[810,891)`。

三字幕在 `[855,883)` 同时覆盖，计 28 个目标帧。源帧用并集对账，三条叠加不会增加 28 帧的源覆盖。

## 换版复核沿用边界

同一卷若只把 B-01 的目标锚点从 810 挪到 815、源区间不动：C101 的交付区间变成 `[815,896)` 而不是 `[810,891)`，文字虽未改，旧审签不能沿用，C101 记 `MOVED` 待复核。C102 同在 B-01 内，也随锚点位移记 `MOVED`；C107 仍在 A-01 内、位置未动，照旧沿用。若新版另有一条同轨字幕挪进 `[855,883)`，原三条与新条都记 `CONFLICT`，原 28 目标帧的旧审签不再算数。证据包 `review.pending` 会按行给出目标帧新旧区间与依据码，`review.carried` 则附 `checks.text_same` 与 `checks.frames_same` 均为真。
